# Flux Docs

Flux・FluxFXの利用者向けドキュメントです。導入から基本操作、応用、トラブルシューティングまでを日本語と英語で案内します。

- **Flux**：VRChat向けの汎用GPU計算フレームワーク。RenderTextureとシェーダーを使い、GPU上でデータの保持・計算・集約を行います。
- **FluxFX**：Fluxを使ったVRChat向けのGPUパーティクル・エフェクトシステム。UnityのInspectorでエフェクトを作成し、UdonSharpから制御できます。
