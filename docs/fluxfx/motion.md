# 動きの変化

NoiseとVortexは速度に加速度を与え、Velocity over Lifetimeは通常の移動に追加の移動を与えます。目的に合う処理を選び、まず単独で効果を確認してから組み合わせます。

## Noise

**Velocity Update → Add Module → Noise** で追加します。粒子の位置とシミュレーション経過時間から求めた揺らぎを、加速度として与えます。

| 項目 | 初期値 | 調整の意味 |
| --- | --- | --- |
| Strength | 1 | 揺らぎによる加速度の強さ。0なら加速しない |
| Scale | 1 | 位置による変化の細かさ。大きいほど短い距離で変化する |
| Speed | 1 | 揺らぎの時間変化の速さ |

各値は0以上です。Noiseは複数のsin関数による揺らぎで、毎フレーム独立した乱数を与える方式ではありません。

Speedを0にすると時間による変化は止まりますが、移動によって位置が変われば加速度も変わり得ます。Scaleを0にすると位置による違いがなくなります。

最初はStrengthを0.2、ScaleとSpeedを1にして試し、Strengthだけを徐々に増やします。加速度が積み重なって速度が増える場合は、[DragやLimit Velocity](./forces.md)を組み合わせます。

## Vortex

**Velocity Update → Add Module → Vortex** で追加します。指定した軸の周りの接線方向へ加速させます。

| 項目 | 初期値 | 意味 |
| --- | --- | --- |
| Center | `(0, 0, 0)` | 軸が通る中心位置 |
| Axis | `(0, 1, 0)` | 回転軸の方向 |
| Strength | 1 | 接線方向の加速度の強さ。0以上 |

Axisは方向として正規化されるため、長くしても強さは増えません。回転方向を逆にする場合はAxisを反転します。ゼロまたは極めて小さい軸では計算を行いません。軸にほぼ重なる粒子にも接線方向の加速は加わりません。

Vortexは中心へ引き寄せる力や軌道への拘束ではありません。接線方向の速度が増えるため、必ず一定半径の円を描くわけではありません。また、距離に比例して加速度を増やす計算ではありません。

例えばLocal空間でCircle形状から発生させ、Centerをゼロ、AxisをY方向、Strengthを0.5にすると、軸から離れた粒子への効果を観察できます。広がりすぎる場合は寿命やDragを調整します。

## Velocity over Lifetime

**Position Update → Add Module → Velocity over Lifetime** で追加します。粒子の寿命の進み具合に応じた直線移動に、周回方向と放射方向の移動を組み合わせます。

| 項目 | 初期値 | 意味 |
| --- | --- | --- |
| Start | `(0, 0, 0)` | 寿命の開始時の追加速度 |
| End | `(0, 0, 0)` | 寿命の終了時の追加速度 |
| Orbital | `(0, 0, 0)` | 各軸の周りの回転に対応する係数 |
| Offset | `(0, 0, 0)` | 周回・放射移動の中心位置 |
| Radial | 0 | 中心から外向きの追加速度。負なら内向き |

追加直後はすべてゼロなので、移動は変わりません。

<span id="start-and-end"></span>

### StartとEnd

粒子の年齢を寿命で割った進行度を使い、StartからEndへ線形補間します。例えばStartを`(0, 0, 0)`、Endを`(0, 2, 0)`にすると、寿命の後半ほど上方向の追加移動が大きくなります。

MainのStart SpeedやGravityで得た速度を置き換えるものではありません。それらを使った通常の移動の後に、補間した速度×経過秒数を位置へ加えます。

<span id="orbital-and-offset"></span>

### OrbitalとOffset

周回方向の追加速度は、`Orbital × (粒子位置 − Offset)`という外積で求めます。軸から遠いほど、この追加速度は大きくなります。

例えばOrbitalが`(0, 1, 0)`ならY軸周りに移動を加えます。この値は度数法の角度ではなく、外積へ直接使う係数です。正負を逆にすると向きも逆になります。

位置を回転行列で厳密に回す処理ではなく、速度から移動量を加算する方式なので、大きな値で一定半径の軌道が保証されるわけではありません。

Offsetは粒子に加える移動量ではなく、中心の座標です。World空間ではワールド位置として指定します。

### Radial

Radialは中心から粒子へ向かう方向の速度です。正なら外向き、負なら内向きに移動を加えます。中心にほぼ一致する粒子には、この移動は加わりません。

粒子を広げたい場合はCircleやSphereなど、中心から離れた位置にも生成するShapeと組み合わせると効果を確認しやすくなります。

<span id="comparison-with-vortex"></span>

## Vortexとの違い

| 項目 | Vortex | Velocity over LifetimeのOrbital |
| --- | --- | --- |
| 更新先 | 保存される速度 | 位置への追加移動 |
| 与えるもの | 接線方向の加速度 | 周回方向の追加速度 |
| 軸からの距離 | 加速度の強さに比例させない | 追加速度が距離に応じて大きくなる |
| Drag・Limit Velocity | 更新した速度に作用する | この追加移動分には作用しない |

Velocity over Lifetimeの移動を抑えたい場合は、Start・End・Orbital・Radialを調整します。Limit Velocityだけで全体の移動速度を制限することはできません。

<span id="compare-while-tuning"></span>

## 比較しながら調整する

最初はStart Speedを0、寿命を3秒にして、対象モジュールだけを有効にすると違いを確認できます。Noiseでは小さいStrength、Vortexでは軸から離れた発生位置、Velocity over LifetimeではStartとEndだけから試してください。

調整後はRendererのCulling Boundsが移動範囲を含むか確認します。プレビューの設定変更では構成が再生成されるため、Restartして同じ時点の動きを比べます。
