# 力と速度

Gravity、Force、Drag、Limit Velocityは **MODULES → Velocity Update** から追加します。いずれも粒子が保持する速度を更新し、その速度を使って位置が進みます。

## Gravity

**Gravity** は一定の加速度をXYZベクトルで指定します。初期値は`(0, -1, 0)`です。更新のたびに、指定した加速度×経過秒数を速度へ加算します。

例えば`(0, -1, 0)`なら、他の速度変更がなければ1秒間にY方向の速度が約1減ります。UnityのPhysics設定から重力を自動取得する機能ではありません。

上向きの初速と組み合わせると、上昇してから落下する動きを作れます。LocalではローカルY、WorldではワールドYを基準に作用します。

## Force

**Force** も一定のベクトルを加速度として速度へ加算します。初期値は`(0, 0, 0)`なので、追加しただけでは動きは変わりません。

現在の実装ではGravityと同じ加算形式で、質量による除算はありません。Gravityを下向きの加速、Forceを横風などの追加の加速として分けると、調整しやすくなります。

例としてGravityを`(0, -1, 0)`、Forceを`(0.5, 0, 0)`にすると、下向きとX方向の加速を組み合わせられます。Forceは一定速度へ固定する設定ではなく、時間とともに速度を変えます。

## Drag

**Drag** は速度を減衰させる係数です。0以上で指定し、初期値は0.5です。

実装は、現在の速度に`exp(-Drag × 経過秒数)`を掛けます。他の加速や制限がない場合、Dragが1なら1秒後の速度は約37%、0.5なら約61%になります。0なら減衰しません。

方向を逆転させる処理ではなく、現在の速度の大きさを徐々に小さくします。GravityやForceなどと併用した場合は、その更新で加えた速度も減衰の対象です。

## Limit Velocity

**Max Speed** は保存される速度の大きさの上限です。0以上で指定し、初期値は1です。上限を超えた場合に、方向を保ったまま速度ベクトルを縮めます。

各軸を個別に制限する設定ではありません。例えば速度が`(3, 4, 0)`、Max Speedが2なら、長さ5のベクトルを`(1.2, 1.6, 0)`へ縮めます。

Max Speedが0なら、この処理後の保存速度は0になります。ただし、Velocity over Lifetimeによる追加移動まで止める設定ではありません。

## 組み合わせて試す

[クイックスタート](./quickstart.md)のエフェクトを使い、MainのStart Speedを1、寿命を3秒程度にして、次の順に比較します。設定値は調整の出発点です。

| 手順 | 設定例 | 観察すること |
| --- | --- | --- |
| 1 | Gravity `(0, -1, 0)` | 時間がたつと下向きへ曲がる |
| 2 | Force `(0.5, 0, 0)`を追加 | 横方向にも加速する |
| 3 | Drag `0.5`を追加 | 速度の増え方と到達距離が変わる |
| 4 | Limit VelocityのMax Speedを`1`にする | 保存速度が上限に収まる |

比較するたびにプレビューをRestartし、同じ経過時間で見ます。モジュールを一時的に無効化すると、個々の効果を確認できます。

<span id="unexpected-motion"></span>

## 期待どおりに動かない場合

| 症状 | 確認すること |
| --- | --- |
| Forceを追加しても変化しない | 初期値はゼロ。ベクトルと有効状態を確認する |
| 加速が弱い | Dragが強すぎないか、Max Speedが低すぎないか確認する |
| 重力の方向が想定と違う | Local／Worldと発生元の回転を確認する |
| 上限より速く見える | Velocity over Lifetimeの追加移動、Local空間での発生元の移動やScaleを確認する |
| 粒子が遠くへ移動して消える | 寿命とRendererのCulling Boundsを確認する |

設定した値はシミュレーション空間の値です。見かけのワールド移動速度は、Transformや別の位置更新も含めて判断してください。
